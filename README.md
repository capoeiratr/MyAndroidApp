# MyAndroidApp

Kotlin ve Jetpack Compose ile modern Android uygulaması.

## 🚀 Başlangıç
Bu proje Android Studio üzerinden doğrudan açılabilecek standart Kotlin DSL ve Gradle Version Catalog yapısıyla hazırlanmıştır.

### Gereksinimler:
* Android Studio (Ladybug veya üstü)
* JDK 17 / Android SDK 35

### Çalıştırma:
1. Android Studio'yu açın.
2. `Open` seçeneği ile bu klasörü seçin.
3. Gradle Sync tamamlandıktan sonra emülatör veya cihazınızda `Run 'app'` (Shift + F10) butonuna basın.
